# Framework landing page

Mode: Persuade. Build directly in code, following the user's instruction to proceed. No standing workflow preference is inferred.

## Direction contract

THESIS: Show a Rust query and its working interface together. Refuse an abstract speed claim followed by feature cards.

OWN-WORLD: Keep the established ivory, charcoal and terracotta identity. Broad open typography, squared code framing, rounded working controls and understated rules distinguish prose from executable proof.

STORY: A developer learns that Hearth is a full Rust framework, tries a local filter and an optimistic write, reads how the server remains authoritative, then opens the starter instructions.

FIRST VIEWPORT: A compact logo and navigation above a large left-aligned two-line headline. Two plain actions precede a full-width connected code/demo workbench, visible in the first desktop viewport. The live list has recognizable issue titles and an obvious filter.

FORM: An interactive technical specimen, pinned to the user's Zero and LiveStore references and existing Hearth brand. Code-led implementation.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
