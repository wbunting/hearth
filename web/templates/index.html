let issues = live_query! {
    IssueItem from i in IssueRow
    where if $(!search.get().is_empty()) {
        i.title contains $(search.get())
    }
    order by i.modified desc
    limit 50
    select { id: i.id, title: i.title }
};

Less between
you and the app.

A framework for the page, the data, and the space between. Pure Rust application code. Generated JavaScript where the browser needs it.

Rust all the way down
Views, handlers, read scopes and write validation live together. You don't maintain a second JavaScript application.
Local queries, live results
Filter, join and sort without a request for every interaction. Declare browser data and indexes alongside the Rust model.
The server stays in charge
Read scopes are mandatory. Writes are explicitly allowed and checked on the server. Browser state is never authorization.
A high performance ceiling
Native Rust server execution, server-rendered startup, indexed local queries and a small JavaScript runtime. Architectural goals, not an unmeasured promise that every Rust app beats every JavaScript app.
